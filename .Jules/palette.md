## 2024-03-22 - Header Focus States Missing
**Learning:** The primary navigation bar components (links and icon buttons) were completely lacking visual feedback for keyboard navigation, meaning screen reader and keyboard-only users could not track their active element easily.
**Action:** Apply `focus-visible:ring-*` classes consistently to interactive elements in structural components like headers and sidebars to ensure base accessibility.
## 2024-05-18 - Keyboard Accessibility on Custom Dropzones\n**Learning:** Custom file upload dropzones that use `div` tags with `onClick` often miss keyboard accessibility (like Space/Enter to trigger the file dialog) and lack visual focus indicators. This causes a significant accessibility barrier for users relying on keyboards.\n**Action:** Always ensure that custom interactive `div` elements have `role="button"`, `tabIndex={0}`, `onKeyDown` handlers for 'Enter'/'Space', and standard visual focus styles (`focus-visible:ring-2` etc.).
